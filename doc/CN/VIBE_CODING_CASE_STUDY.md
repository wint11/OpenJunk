# OpenJunk - Vibe Coding 案例研究

## 项目概述

**OpenJunk** 是一个现代化的全栈学术期刊平台，采用 Next.js 16 构建。项目旨在"变废为宝"，为学术"垃圾"论文提供开放的展示、评审和交流平台。这个项目完美展示了如何通过 Vibe Coding 方法快速构建复杂的全栈应用。

## 🎯 Vibe Coding 核心理念体现

### 1. 快速原型验证
- **从0到1的构建速度**：完整的多角色权限系统、AI集成、移动端支持
- **敏捷迭代**：从CTF平台转型为学术期刊平台，展示了快速转向能力
- **功能优先**：先实现核心功能，再优化用户体验

### 2. AI驱动的开发模式
- **AI预审系统**：集成DeepSeek API进行论文质量评估
- **智能评分**：AOI（学术过端指数）算法自动计算
- **内容安全**：AI注入检测和防护机制
- **提示词工程**：精心设计的AI分析提示词

### 3. 多平台一体化开发
- **Web端**：Next.js全栈应用
- **移动端**：Uni-app跨平台移动应用
- **桌面端**：Electron聊天客户端
- **统一API**：RESTful API服务所有客户端

## 🛠 技术架构亮点

### 前端技术栈
```
Next.js 16 (App Router) + React 19 + TypeScript
Tailwind CSS v4 + shadcn/ui
Framer Motion + Three.js (3D效果)
```

### 后端技术栈
```
Next.js API Routes
Prisma ORM (SQLite/PostgreSQL)
NextAuth.js v5 (认证)
Zod (数据验证)
```

### AI集成
```
DeepSeek API (内容分析)
OpenAI SDK (多模型支持)
PDF解析 (pdf-parse-fork)
```
